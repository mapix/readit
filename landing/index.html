保留原排版的双语对照

每段原文下面，就是它的译文。

每一页都按原 PDF 的矢量内容绘制，公式、图表、字体、分栏都和原文一样。读到哪一页，就翻译到哪一页，并预翻后两页；翻译完成时页面不会抖动，已翻译过的内容不会重复翻译。

3.1 Encoder and Decoder Stacks

3.1 编码器与解码器堆栈
The encoder is composed of a stack of N = 6 identical layers. Each layer has two sub-layers. The first is a multi-head self-attention mechanism, and the second is a simple, position-wise fully connected feed-forward network.
编码器由 N = 6 个相同的层堆叠而成。每一层包含两个子层：第一个是多头自注意力机制，第二个是简单的逐位置全连接前馈网络。
Attention(Q, K, V) = softmax(QKᵀ / √dk) V
↑ 公式、表格、伪代码自动跳过，不做无意义的翻译。

像沉浸式翻译一样，
但是给 PDF 用的。

按段落理解版面，单栏、双栏、图注、脚注都能识别；页面跟随“默认 / 护眼 / 夜间”主题着色，文字保持矢量清晰，不会发虚。

  • 原文 / 双语 一键切换，阅读位置不变
  • 默认只提前翻译 2 页，省时省额度
  • 划词即译，导出完整的双语 PDF
  • 翻译模型可选：Claude、GPT、DeepSeek、Qwen…
MarginNote 式笔记

选中、摘录、连成知识网络。

标注模式下，选中文字后弹出浮动工具条，点一下颜色就生成卡片，同时挂到脑图上。阅读模式下，选中就只是普通的文字选择。

🖍

八色摘录

浮动工具条一点即摘录；也支持自动摘录和框选（把公式、图表截成图片卡片）。

💬

卡片与评论

卡片可以加标题、多条评论，自动附上译文；点击页面上的高亮即可重新打开卡片。

🌿

脑图

可以拖拽整理，Tab 和 Return 快速建节点，折叠展开、调整层级，双击节点回到原文。

🔗

跨 PDF 关联

一个笔记本可以包含多个 PDF，不同文档的卡片可以双向链接，一点就跳到另一份文档。

🪟

多窗口 · 桌面小组件

每个 PDF 一个窗口；收起后只在桌面留一个可拖动的播放器，边听讲解边做别的事。

🎨

三种主题

默认、护眼、夜间三种主题，配色延续 MarginNote 的风格，长时间阅读也不累眼。

Readit for Mac

版本 0.2.0 · macOS 14 Sonoma 及以上 · Apple Silicon
⬇︎ 下载 Readit-0.2.0.zip
首次打开时，如果 macOS 提示“无法验证开发者”，请在 Finder 中右键 Readit → 打开；也可以在终端执行 xattr -dr com.apple.quarantine /Applications/Readit.app。
1 · 安装解压后把 Readit 拖进「应用程序」。
2 · 配置模型在设置里填入网关地址和 API Key，再选择翻译、AI 和 TTS 模型。
3 · 开始读拖入一个 PDF，按 ⌘2 切换到双语，按 ⌘⇧L 让 AI 开讲。
