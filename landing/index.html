01

双语精读

每段原文下面，
就是它的译文。

像沉浸式翻译一样，但原生深入 PDF 矢量层与动态网页。

每一页都按原 PDF 的矢量内容绘制，公式、图表、字体、双栏分栏都和原文分毫不差。读到哪一页就翻译到哪一页并预翻后两页；翻译完成时页面不抖动，已翻译内容绝不重复消耗额度。

矢量级双语对照合成 · 每一段公式与图注均精准对齐。

哪些设备可以运行 Readlet？

Readlet 原生支持 macOS 14 Sonoma 及更高版本（Apple Silicon 与 Intel 通用二进制），以及 iOS / iPadOS 17.0 及更高版本的 iPhone 与 iPad。

「动态交互网页导入」和「网页转静态 PDF」有什么区别？

默认的「可交互网页（DocKind.web）」模式仅保存网址与你的批注、朗读、脑图等轻量叠加数据，完整保留网页内 D3 / Canvas / iframe 动态图表的实时交互，默认自动移除周边非正文干扰（可按篇随时关闭），并通过无分页连续锚点同步 0%–100% 阅读进度；若你需要固定版面归档，也可在导入时选择「提取为静态 A4 PDF」。

使用 AI 逐页语音解读必须配置付费 TTS 模型吗？

不需要。Readlet 默认使用 macOS 与 iOS 自带的系统离线语音，零配置、免费开箱即讲；当你有更高音质需求时，可随时切换至主网关、OpenAI、Gemini、通义千问 Qwen-TTS、Azure、ElevenLabs、MiniMax 或火山引擎豆包语音。

哪些数据会同步到 iCloud？语音缓存会占满我的云盘吗？

Readlet 严格遵循轻量化云同步原则：仅同步 PDF 原文、动态网页 URL 与阅读锚点、摘录卡片、思维导图、闪卡、翻译文本、讲解文稿（p*.json）及网关配置；体积较大的合成音频（.m4a / .wav）与导出视频（.mp4）仅保存在本机并支持按文档一键清理，绝不占用你的 iCloud 空间。

macOS 安装包是否经过 Apple 官方签名与公证？

是的。官网发布的每一个 Readlet 安装包均经过 Apple Developer ID 签名、Apple Notary 官方公证与票据订合（Stapled），解压后拖入「应用程序」即可直接安全运行。
